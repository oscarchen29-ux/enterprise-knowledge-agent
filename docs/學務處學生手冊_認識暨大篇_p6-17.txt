認識暨大篇01
校
 
名由來及校徽的意義
　　清光緒三十二年，兩江總督端方為廣來學，遂奏請於南京設立學堂，並取
尚書禹貢「朔南暨，聲教訖于四海」之義，得「暨南」一詞，作為宣揚華夏文
化之高等學堂， 遂訂名 「暨南學堂」 ， 寓義深遠。 其後因局勢板蕩， 雖幾經易址、
停辦的變遷與顛沛流離的歷程，是香火不絕。
　　民國七十九年間，教育部配合國家建設六年計劃「強化人力培育以厚植產
業發展潛力」之政策目標，積極增設大專院校，使具光榮歷史之「國立暨南大
學」在台設校，並於原「國立暨南大學」加上「國際」二字，以示本校長程校
務規劃乃以發展世界文化交流，走上國際知名學府自期。

認識暨大篇 01
設計題材
　　以校名暨南 CHI - NAN 之「C、N」字首，融合中國傳統紋飾及地球形設計而
成， 設計雖結合中國化、 現代化， 造成簡潔易明， 蘊涵本校設校宗旨、 教育理念 ；
將本校得天獨厚的環境， 以更積極創新的作法， 為國人開創更美好的教育遠景。
造形意義
　　對稱循環的紋飾結構，代表僑界和國內，象徵僑教功能及海外支持力量的
雄厚、自強不息。將「C、N」設計襯托出「中」字造型，躍然地球之上，代表
本校富中華文化 「中道」 之精神。 外形以 「圓」 形彰顯出 「允執厥中， 止於至善」
之含義。
色彩表現
　　以穩健、自然、務實的深藍色，為校徽注入更多的生命和深遠的意義，象
徵本校在「誠樸弘毅、務本致用」校訓的推動之下，必能促使校務朝向更完善、
更和諧、更美好的境界。

一、依據

野的優秀人才。

認識暨大篇 01
校
 
教育目標與學生核心能力
一、依據
　　本校「誠樸弘毅、務本致用」教育理念，並秉持強化僑教設校精神，以傳
承既有文化、造就健全人才、厚植社會文化資本為三大教育重點，並強調培育
本校學生在人文與科學、通才與專才、傳統文化與現代文化間平衡發展。
二、教育目標
　　培育兼具積極態度與服務熱誠、人文關懷與科學素養、終身學習與國際視
野的優秀人才。
三、學生核心能力
　　對應本校教育理念與前述教育目標，本校學生八大核心能力設計如下：
( 一 ) 道德思辨與實踐能力。
( 二 ) 人際溝通與表達能力。
( 三 ) 獨立思考與創新能力。
( 四 ) 人文關懷與藝術涵養。
( 五 ) 專業知能與數位能力。
( 六 ) 團隊合作與樂業倫理。
( 七 ) 全球視野與尊重多元文化。
( 八 ) 社區參與與公民責任。
