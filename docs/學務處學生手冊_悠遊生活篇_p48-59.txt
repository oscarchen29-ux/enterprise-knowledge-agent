　　大家或多或少都聽過埔里，沒聽過埔里米粉總喝過埔里的山泉水吧？！然

一、學生餐廳區
　　學校餐廳區是每位暨大學生每天要報到多次的地方，學校為體貼同學，
此區提供同學日常生活基本需求，減少採買上舟車勞頓，餐廳、便利商店、
提款機、i 郵箱、生活商場─暨大書坊等介紹如下：
( 一 )-餐廳 ： 1、 2 樓餐廳打造美食街的用餐氣氛， 設有早午餐店、 異國料理、
清真料理、中式麵 ( 飯 ) 食、義大利麵、燉飯、蔥油餅、自助餐、日
式鍋燒、 韓式鍋燒、 越式炒泡麵、 泰式打拋料理、 港式料理、 咖啡簡餐，
並有知名連鎖品牌進駐 (114 學年度例如：路易莎、八方雲集 )，為學
生提供各式選擇。整體提供多元舒適的客席空間，讓餐廳不再侷限於
享受美食；伴隨窗外美景，給予師生一個優質的交流或自習場域，大
片的透光設計讓自然光自在灑進，塑造被大自然擁抱的舒適環境。( 附
圖 1、2)
( 二 ) -便利商店：設有全家便利商店「學餐店」以「人文店」，學餐店位於
餐廳區 1 樓、人文店位於人文學院 1 樓與地下 1 樓間，販售商品種類
豐富、生活服務貼心便利，提供師生如家般的便利生活。( 附圖 3、4)
( 三 ) -提款機：餐廳區設有 3 部自動櫃員機 (ATM) 提供基本金融服務，分別
位於中華郵政區域、餐廳 1 樓、超商內；行政大樓一樓電梯前亦設有
1 部 ATM。
( 四 ) -i 郵箱：餐廳區中華郵政 ATM 旁設「i 郵箱」，提供 24 小時全年無休
的自助取 / 寄郵件服務，創造智慧用郵新體驗。( 附圖 5)
( 五 ) -生活商場─暨大書坊：設於餐廳區便利超商旁，服務項目包含代訂教
科書、各類圖書、文具、禮品、生活、廚房、浴廁、臥室、五金及二

住：宿舍
　　大家應該已經見到自己的室友了吧？在暨大的宿舍生活，其實相當自在
愜意。宿舍無門禁時間，進出皆採用磁扣感應系統，不論早晚，只需感應磁
扣，系統辨識完成後，宿舍大門便會自動開啟，既安全又方便。
每四間寢室共用一間綜合衛浴空間，包含淋浴間、廁所、洗衣區及曬衣場等
設施。若不想手洗衣物，每層樓均設有投幣式洗衣機與烘衣機，歡迎同學至
洗衣區使用。此外，宿舍內亦設有飲水機，方便泡麵或沖泡熱茶。
若臨時嘴饞，宿舍一樓設有自動販賣機，隨時提供各式飲料與零食。
家人若需寄送物品或信件，只需正確填寫宿舍地址與房號，掛號信與包裹會
送達宿舍服務中心，普通信件則會放置於信件櫃中。
如需聯繫宿舍管理員，以下是聯絡方式：
•-宿舍服務中心｜分機：5200
