國立暨南國際大學圖書館學位論文繳交注意事項（來源：csie.ncnu.edu.tw/upload 轉載自圖書館公告，2022/05/10修訂；含論文格式規定，適用全校各系所研究生，資工系亦引用本規定）

本校畢業生辦理畢業離校手續須完成圖書館相關作業程序，摘要如下：

【壹、離校程序】
一、登錄本校「電子學位論文服務」系統（http://www.airitietds.com/ETDS/?SchoolID=U0020），輸入論文基本資料、上傳論文電子檔案，審核通過後，列印並簽署「國立暨南國際大學博碩士論文授權書」1張。
二、依系所辦公室核發之帳號密碼，登入國家圖書館「臺灣博碩士論文知識加值系統」，上傳論文電子檔案及書目檔，勾選授權選項後，列印「國立暨南國際大學學位論文授權書」2張並簽署上傳（請勿上傳本校論文系統之授權書），再送出審核。
三、自110學年第2學期開始，研究生畢業離校改採線上流程辦理，辦理離校手續前需先至圖書館辦理：(一)完成本校及國家圖書館論文系統上傳程序。(二)至圖書館繳交紙本論文及授權書正本：紙本論文需有封面(含書背)、口試委員審定書及內文，繳交冊數共3冊：1冊送存國家圖書館（一定要平裝），2冊本校圖書館留存(平裝、精裝皆可，請擇一)；授權書正本共3張：學校1張、國家圖書館2張，均需簽名。(三)若紙本論文需延後公開，須填具國圖與本校延後公開申請書一併繳交。(四)受理處為本校圖書館1樓櫃檯。
四、歸還所有借自本校及館際合作之館藏資料，並繳清積欠之罰款。

【貳、論文格式說明（詳細規定請見「學位論文格式暨範本」https://www.airitietds.com/ETDS/ETDSNews/ViewFile/2019050004）】
一、基本寫作說明：建議使用Word 2003以上版本或LibreOffice Writer撰寫；除外國語文學系外，其他各系(所)之論文以中文撰寫為原則，如同意以外文撰寫，應於修業規則中明訂適用規定，以外文撰寫之論文仍須有中文摘要；論文字型中文為標楷體/細明體/新細明體，英文為Times New Roman/Arial/Arial Black；採直式橫書方式撰寫；圖檔請使用.gif和.jpg格式。
二、頁別順序（除以下內容請勿自行增加其他內容）：(一)封面（標題頁）(二)學位考試委員會口試審定書 (三)致謝辭/致謝詞/謝誌(如無可省略) (四)摘要 (五)Abstract (六)目次 (七)表目次 (八)圖目次 (九)符號表(如無可省略) (十)縮寫表(如無可省略) (十一)詞彙表(如無可省略) (十二)論文正文 (十三)參考文獻 (十四)附錄。
三、頁碼編排：封面與審定書不編頁碼；正文前的頁碼（致謝辭、摘要、Abstract、目次、表目次、圖目次）一律使用小寫羅馬數字；論文正文以阿拉伯數字重新編碼。
四、封面：邊界上下各3公分，字體16或18號，置中對齊；論文名稱居版面正中央；指導教授姓名後需加「博士」二字；畢業年月輸入實際畢業年月(不加日)，用阿拉伯數字書寫，例如中華民國111年6月。
五、論文正文格式：邊界（含頁碼）上下左右一律3公分為原則；行距1.5倍行高；字體以標楷體或新細明體12號字為原則。
六、參考文獻起始頁版面上方中間需有「參考文獻」標題；附錄起始頁版面上方中間需有「附錄」標題，附錄子標題須列入目次。

【參、轉檔與上傳注意事項】
一、全文電子檔必須為「一個」單一完整的PDF檔（含封面、審定書、致謝辭、摘要、Abstract、目次、正文、參考文獻、附錄等）。上傳前先以掃毒軟體檢查檔案。檔名不可使用中文或全形空格及特殊符號 ~ . * / \ ( ) + [ ] { }。
二、上傳至本校「電子學位論文服務系統」時，須輸入論文基本資料（校院系、畢業學年度、研究生中英文姓名、口試通過日期、論文頁數、中英文關鍵字、中英文摘要、目次、參考文獻等），並上傳整篇論文PDF（檔案大小不可超過25MB），審核時間約1~3個工作日。
三、上傳至國家圖書館「臺灣博碩士論文知識加值系統」時，須以系辦核發之帳號密碼登入，上傳論文全文檔及書目資料，並可設定全文公開方式與時間（校內外立即開放、延後公開或其他）。

【肆、紙本論文規格】
一、繳交紙本論文1冊送存國家圖書館（一定要平裝），2冊本校圖書館留存(平裝、精裝皆可，請擇一)。
二、精裝本封面黑色燙金字體；平裝本採200磅淡綠色雲彩紙印刷，封面須上光。內頁均採用80磅之白色模造紙印刷；封背字型以標楷體為原則。
